MarketDataLoader (CSV Ingestion Engine)

src/MarketDataLoader.cpp & include/MarketDataLoader.h

Parses historical OHLCV data directly from CSV files into memory-aligned PriceBar structs in a contiguous std::vector. Enforces strict chronological ordering to guarantee deterministic backtesting.

Performance Guarantee: O(N) sequential stream parse, Zero copy overhead
  • ✓ Streams file without loading full raw text into heap
  • ✓ Validates Date, Open, High, Low, Close, Volume schema
  • ✓ Cache-friendly contiguous memory layout (std::vector<PriceBar>)

Why Single-Threaded Backtesting?

Historical backtesting is strictly sequential: you cannot know day T+1 before day T. Multi-threading in backtesting introduces non-determinism, race conditions, and heavy lock contention. A single-threaded loop traversing contiguous vectors leverages L1/L2 CPU cache locality, with explicit state updates. Native throughput has not been benchmarked.

Historical-data assumptions

A common bug in quant systems is accidental peeking at future price data. In this engine, Strategy::evaluate(index, data) and the Indicators namespace strictly compute statistics using indices ≤ index, for the built-in strategies. Custom strategies receive the full data vector and must avoid future data; same-close execution remains a modeling assumption.

Realistic Friction Accounting

Many naive backtesters ignore commissions and price slippage, generating synthetic profits. This system deducts proportional commissions (e.g., 0.1%) on every buy and sell, tracks volume-weighted average entry prices (VWAP), and models realistic cash liquidation constraints.

Production Scaling Roadmap

For live execution, the architecture extends into an Event-Driven model: replacing the direct loop with lock-free Ring Buffers for MarketDataEvent, SignalEvent, and OrderEvent, accompanied by Level 2 Order Book reconstruction and cross-asset covariance matrices.

// src/Backtester.cpp
#include "Backtester.h"
#include "Portfolio.h"

Backtester::Backtester(const BacktestConfig& config)
    : config_(config) {
}

BacktestResult Backtester::run(const std::vector& data, Strategy& strategy) {
    BacktestResult result;
    result.initial_capital = config_.initial_capital;
    
    Portfolio portfolio(config_.initial_capital, config_.commission_rate);
    strategy.reset();
    
    result.equity_curve.reserve(data.size());
    
    for (size_t i = 0; i < data.size(); ++i) {
        const auto& bar = data[i];
        
        // 1. Evaluate strategy with strict historical window
        Signal signal = strategy.evaluate(static_cast(i), data);
        
        // 2. Execute trades based on signal
        if (signal == Signal::BUY && portfolio.getPositionQuantity(config_.symbol) == 0) {
            double cost_per_share = bar.close * (1.0 + config_.commission_rate);
            int max_shares = static_cast(portfolio.getCash() / cost_per_share);
            int qty = std::min(config_.position_size, max_shares);
            
            if (qty > 0) {
                portfolio.executeTrade(config_.symbol, OrderSide::BUY, qty, bar.close);
                
                TradeRecord trade;
                trade.date = bar.date;
                trade.symbol = config_.symbol;
                trade.side = OrderSide::BUY;
                trade.quantity = qty;
                trade.price = bar.close;
                trade.commission = qty * bar.close * config_.commission_rate;
                trade.realized_pnl = 0.0;
                result.trades.push_back(trade);
            }
        } else if (signal == Signal::SELL && portfolio.getPositionQuantity(config_.symbol) > 0) {
            int qty = portfolio.getPositionQuantity(config_.symbol);
            double realized_pnl = portfolio.executeTrade(config_.symbol, OrderSide::SELL, qty, bar.close);
            
            TradeRecord trade;
            trade.date = bar.date;
            trade.symbol = config_.symbol;
            trade.side = OrderSide::SELL;
            trade.quantity = qty;
            trade.price = bar.close;
            trade.commission = qty * bar.close * config_.commission_rate;
            trade.realized_pnl = realized_pnl;
            result.trades.push_back(trade);
        }
        
        // 3. Mark to market equity
        double current_value = portfolio.getTotalValue(config_.symbol, bar.close);
        result.equity_curve.push_back(current_value);
    }
    
    // Close open positions at final bar close
    if (portfolio.getPositionQuantity(config_.symbol) > 0) {
        int qty = portfolio.getPositionQuantity(config_.symbol);
        double final_price = data.back().close;
        double realized_pnl = portfolio.executeTrade(config_.symbol, OrderSide::SELL, qty, final_price);
        
        TradeRecord trade;
        trade.date = data.back().date;
        trade.symbol = config_.symbol;
        trade.side = OrderSide::SELL;
        trade.quantity = qty;
        trade.price = final_price;
        trade.commission = qty * final_price * config_.commission_rate;
        trade.realized_pnl = realized_pnl;
        result.trades.push_back(trade);
        
        result.equity_curve.back() = portfolio.getCash();
    }
    
    result.final_value = result.equity_curve.back();
    double benchmark_return_pct = 0.0;
    if (!data.empty() && data.front().close > 0.0) {
        benchmark_return_pct = ((data.back().close - data.front().close) / data.front().close) * 100.0;
    }
    
    result.metrics = RiskMetrics::calculate(result.initial_capital, result.equity_curve, result.trades, benchmark_return_pct);
    return result;
}
