# Project overview

A C++17 historical backtester for SMA and RSI strategies, with CSV input, commission accounting, cash-constrained positions, equity curves, and portfolio risk statistics. CMake builds the native binary and five CTest targets.

The separate JavaScript browser application includes additional strategies and a scripted terminal. It does not run the C++ binary. Neither environment demonstrates live trading profitability or a measured native throughput claim.

See the [README](../README.md) for reproducible build commands and scope.
